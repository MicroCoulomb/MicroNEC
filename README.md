# MicroNEC

Private, mobile-first NEC quick checks using a 2023 NEC baseline.

## Run locally

```powershell
npm.cmd install
npm.cmd run dev
```

## Verify and deploy

```powershell
npm.cmd run test
npm.cmd run build
```

Import this folder into Vercel. It detects Vite and deploys the `dist` output.

This is a design aid. Confirm local amendments, equipment listings, and final design with the AHJ.
